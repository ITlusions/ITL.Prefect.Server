# 4.2 Troubleshooting

| Symptom | Likely cause |
|---|---|
| Server pod `CrashLoopBackOff`, `ConnectionRefusedError` on 5432 | Postgres wasn't ready. Run `kubectl -n prefect rollout restart deploy/prefect-server` |
| Work-pools Job `Error`, `401 Unauthorized` | The Job lacks `PREFECT_API_AUTH_STRING`, or the Secret is missing |
| Argo CD shows `OutOfSync`, hook never completes | A stale hook Job from an earlier sync. Delete the Job and sync again |
| Certificate stays `False` | Run `kubectl -n prefect get challenge`. HTTP-01 needs port 80 reachable on the ingress IP |
| `401` in the browser UI | Expected, since basic auth is on. The UI has no login prompt yet |
