# 3.3 Work pools

The chart creates the `itl-amalia` pool of type `kubernetes`. The worker picks up runs from it.

The `work-pools` Job uses the basic-auth credential, so the Secret must exist first.

The worker is a separate chart (`ITL.Prefect.Worker`). It isn't deployed yet. Once deployed, it needs `PREFECT_API_AUTH_STRING` set to the `auth-string` value.
