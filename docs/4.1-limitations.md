# 4.1 Known limitations

- **Postgres storage is `emptyDir`.** Data is lost when the pod restarts. Enable `postgres.persistence` or move to CloudNativePG.
- **Basic auth only.** There's no SSO yet. An OIDC design (Keycloak, oauth2-proxy, or a plugin) is under discussion.
- **No NetworkPolicy enforcement.** The cluster's flannel CNI doesn't enforce NetworkPolicy objects.
- **Startup race.** The server can crash once if it starts before Postgres accepts connections. Restarting the deployment fixes it.
- **Demo labels.** `commonLabels` still says `environment: "demo"`.
- **Image pinning.** The Prefect image is pinned by tag, and the bootstrap image `alpine/k8s:1.31.4` is pinned by tag, not digest.
